接入文档

OpenAI-compatible API 与 Anthropic Messages 兼容层

Docker 默认使用公共 API 端口 8877；反向代理部署可直接改成实际 HTTPS 地址。

OpenAI 鉴权 Authorization: Bearer YOUR_API_KEY Anthropic 鉴权 x-api-key: YOUR_API_KEY

将 YOUR_API_KEY 替换为上方保存或生成时显示的明文 Key；掩码不能用于客户端。

GET /healthz 健康检查，无需 API Key
GET /v1/models 可用模型目录
POST /v1/chat/completions Chat Completions，支持流式与非流式文本
POST /v1/responses Responses API 兼容子集
POST /v1/messages Anthropic Messages 实验性兼容层
POST /v1/messages/count_tokens 近似 Token 计数

兼容范围
  • 模型 ID 以 GET /v1/models 返回的完整值为准；目录中出现不代表账号一定有对应资格或额度。
  • Responses API 为兼容子集；涉及工具调用时优先使用流式 Chat Completions。
  • Anthropic Messages 仍属实验性适配，count_tokens 返回近似值。
